# Sales Data Analysis & Sales Prediction

## 📌 Project Overview
This project focuses on analyzing sales performance and building a Machine Learning model to predict future sales using Python and Power BI. It includes data cleaning, exploratory data analysis (EDA), predictive regression modeling, and an interactive Power BI dashboard.

---

## 🛠️ Tools & Technologies Used
- **Python**: Data Cleaning, EDA, and Machine Learning[cite: 1, 3]
  - `pandas` & `numpy` for data manipulation[cite: 3]
  - `matplotlib` & `seaborn` for data visualization[cite: 3]
  - `scikit-learn` for Linear Regression modeling[cite: 3, 4]
- **Power BI**: Interactive dashboard creation[cite: 1, 3]
- **Dataset**: Sales data with 700 records and key business metrics[cite: 3, 4]

---

## 📊 Key Findings & Insights
- **Total Sales**: $118,726,350.26[cite: 4]
- **Total Profit**: $16,893,702.26[cite: 4]
- **Total Units Sold**: 1,125,806[cite: 4]
- **Top Product**: *Paseo* generated the highest sales among all products[cite: 4].
- **Top Segment**: *Government* segment contributed the highest sales[cite: 4].
- **Top Country**: *United States of America* recorded the highest sales[cite: 4].
- **Yearly Trend**: Sales and profit were significantly higher in 2014 compared to 2013[cite: 4].

---

## 🤖 Machine Learning Model Performance
A **Linear Regression** model was trained using an 80:20 train-test split[cite: 4, 5]:
- **Mean Absolute Error (MAE)**: 82,876.54[cite: 5]
- **Root Mean Squared Error (RMSE)**: 114,244.40[cite: 5]
- **R² Score**: 0.7643 (explains ~76.43% of sales variance)[cite: 5]
